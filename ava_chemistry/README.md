# AVA 01610 Chemistry Knowledge Module

Read-only educational data structured from the supplied S-block and common-cation-test images.

## Contents

- `knowledge.json`: 13 displayed S-block entries and 10 cation-test reference entries.
- `knowledge.py`: JSON loader and structural integrity checks.
- `tests/test_knowledge.py`: standard-library unit tests.
- `.github/workflows/ava-chemistry-tests.yml`: Python 3.12 CI, manual `workflow_dispatch`, pull-request and main-branch path triggers.

## Run locally

From the repository root:

```powershell
python -m unittest discover -s ava_chemistry/tests -v
```

No lab work or external network calls are performed. The visible colours are reference observations, not experimental results generated by AVA. Cation identification requires appropriate confirmatory procedures; follow approved laboratory safety procedures.
